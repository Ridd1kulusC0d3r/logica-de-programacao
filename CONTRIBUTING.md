# Contribuindo

Este repositório é também um laboratório de boas práticas.

## Fluxo
1. crie uma branch;
2. faça uma mudança pequena;
3. rode `ruff check .` e `pytest`;
4. escreva commit descritivo;
5. abra PR explicando o que aprendeu e quais decisões tomou.

Evite commits gigantes. O histórico deve contar a evolução do aprendizado.
