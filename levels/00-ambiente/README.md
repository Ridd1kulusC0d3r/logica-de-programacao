# Ambiente, terminal e Git

## Resultado esperado
Ao final deste nível, você deve conseguir usar os conceitos sem depender de um tutorial passo a passo.

## Conteúdo
- instalar/verificar Python
- criar e ativar venv
- usar pip
- executar scripts
- usar git status/add/commit/log

## Missões
1. **Explique:** defina cada conceito com suas palavras.
2. **Digite:** crie três exemplos mínimos.
3. **Quebre:** provoque dois erros e leia o traceback.
4. **Resolva:** faça cinco exercícios sem consulta.
5. **Teste:** escreva pelo menos um teste automatizado quando aplicável.
6. **Refatore:** reduza duplicação e melhore nomes.
7. **Transfira:** use o conceito em um problema diferente.

## Entrega
Monte um laboratório reproduzível e faça seu primeiro commit.
